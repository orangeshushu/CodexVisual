# CodexVisual Promotion Copy

Use these snippets when announcing CodexVisual. Keep links pointed at the GitHub repository and the latest release download.

## One-line Pitch

CodexVisual is an open-source Codex quota tracker that shows plan-aware 5-hour and weekly limits in the macOS menu bar or Windows taskbar tray.

## Short English Post

I built CodexVisual, a small open-source tool for people using Codex heavily.

Plus users see both the 5-hour and weekly windows directly in the macOS menu bar or Windows taskbar tray. Pro users keep the weekly view. It reads local Codex data, ignores expired events, and does not read auth tokens or call an external quota API.

macOS and Windows downloads are available here:
https://github.com/orangeshushu/CodexVisual

## Longer Product Description

CodexVisual is a focused desktop utility for developers who want Codex quota visibility without opening logs. Plus shows the 5-hour and weekly windows; Pro shows the weekly window only. The app reads local Codex data, filters expired quota events, supports manual and smart refresh, and provides English and Chinese UI.
