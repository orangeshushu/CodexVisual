Frequently asked

Good to know before you install.

Which Codex limit does CodexVisual show?

CodexVisual shows the account-wide weekly Codex quota, its remaining percentage, and the reset countdown. The current interface does not show a separate five-hour limit.

Does it need an OpenAI API key or auth.json?

No. CodexVisual does not ask for an API key and does not read auth.json. On macOS it first asks the local Codex app service for the current account quota, with recent local sessions and logs as fallbacks.

How often does the Codex quota refresh?

Smart mode normally refreshes every 15 seconds and schedules a new read just after an approaching reset. You can also choose 60-second, 5-minute, or manual refresh modes.

Which platforms are supported?

CodexVisual supports macOS 13 or later and Windows. The macOS installer is signed with Developer ID, notarized by Apple, and accepted by Gatekeeper.

Is CodexVisual an official OpenAI application?

No. CodexVisual is an independent, open-source utility for Codex users and is not affiliated with or endorsed by OpenAI.

中文简介

只看当前有效的 Codex 每周额度。

CodexVisual 是一款免费、开源的 Codex 额度查看工具，支持 macOS 菜单栏和 Windows 任务栏。最新版只显示当前账号的每周剩余额度、重置倒计时和本次数据来源，不再显示单独的五小时限额。

macOS 版优先通过本机 Codex 服务读取当前登录账号的数据，仅在服务暂时不可用时回退到近期本地会话与日志；无需复制 API key，也不会读取 auth.json 或把额度数据发送给外部额度服务。
