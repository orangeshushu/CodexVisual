CodexVisual

Know how much Codex quota is left—and exactly when it resets—without opening logs or leaving your workflow.

CodexVisual keeps the account-wide weekly limit, reset countdown, and current reading source in the macOS menu bar or beside the Windows taskbar.

One focused signal

The details you need, where you already look

Account-wide quota

Shows the primary weekly Codex limit and ignores model-specific quota streams.

Reset countdown

Counts down to the next quota-window reset, down to the minute.

Smart refresh

Refreshes automatically, then schedules a fresh read just after an approaching reset.

At-a-glance state

Clear threshold colors make the remaining percentage easy to scan while you work.

Local by design

Uses the Codex data already on your computer

There is no second account to connect and no token to paste. On macOS, CodexVisual asks the local Codex app service for the quota of the currently signed-in account, then uses recent local sessions and logs only as fallbacks. On Windows, it reads recent local Codex session and log events.

  • Does not read auth.json or send quota data to an external service
  • Shows the data source and latest local reading time
  • Smart, 60-second, 5-minute, and manual refresh modes
  • English and Chinese interface

中文简介

不用翻日志，也能随时看到 Codex 剩余额度

CodexVisual 是一款免费、开源的轻量级额度查看工具，支持 macOS 菜单栏和 Windows 任务栏。它显示当前账号的每周剩余额度、精确重置倒计时和本次数据来源，并自动忽略模型专属额度。

macOS 版优先通过本机 Codex 服务读取当前登录账号的数据，仅在服务暂时不可用时回退到近期本地会话与日志；无需复制 token，也不会读取 auth.json 或把额度数据发送给外部服务。
