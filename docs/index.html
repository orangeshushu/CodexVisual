Quick answers

Before you install.

Which limit does it show?

The account-wide weekly Codex quota, remaining percentage, and reset countdown. There is no separate five-hour card.

Does it need an API key?

No. CodexVisual reads quota data locally and does not read auth.json.

Which platforms are supported?

macOS 13 or later and Windows. The macOS release is signed and notarized by Apple.
